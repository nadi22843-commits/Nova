# Nova — просмотр на телефоне

Самый простой вариант (телефон и ПК в одной Wi‑Fi сети):

```bash
npm install
npm run mobile:lan
```

Откройте Expo Go на iPhone и отсканируйте QR-код из терминала.

Если LAN недоступен, резервный вариант:

```bash
npm run mobile:tunnel
```

`@expo/ngrok` уже указан локально в `apps/mobile`, поэтому Expo не должен просить глобальную установку ngrok.

Важно: VPN/Proxy на ПК или телефоне может мешать и LAN, и tunnel. Для первого запуска лучше временно отключить VPN, при этом не нужно отключать Windows Firewall целиком.
