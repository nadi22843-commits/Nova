# Запуск Nova на телефоне через Expo Go

Мобильная часть обновлена до Expo SDK 57. Исходный код экранов, веб-версия и API не менялись.

## Первый запуск

Нужен Node.js 22 (рекомендуется актуальный LTS) и свежий Expo Go.

Из корня проекта:

```bash
npm install
npx expo login
npm run mobile
```

В Expo Go на телефоне войдите **в тот же Expo-аккаунт**, что и в терминале. Затем отсканируйте QR-код.

## Если телефон не видит компьютер

Попробуйте туннель:

```bash
npm run mobile:tunnel
```

Если Expo попросит установить компонент для tunnel, подтвердите установку.

## Проверка зависимостей

```bash
npx expo-doctor
```

## Важно

- Не запускайте старый `node_modules` от SDK 52. После распаковки нового архива выполните `npm install`.
- На iPhone актуальный Expo Go требует входа в Expo и в приложении, и в CLI одним аккаунтом.
- Если QR не открывается по LAN, используйте `npm run mobile:tunnel`.
