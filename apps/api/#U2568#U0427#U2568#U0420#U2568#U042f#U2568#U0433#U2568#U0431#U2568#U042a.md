# Nova API

## Что нужно

- Node.js **22 LTS** (минимум 20.12 — нужен встроенный `process.loadEnvFile`).
- PostgreSQL 14 или новее. Локально проще всего через Docker:

```
docker run -d --name nova-db \
  -e POSTGRES_USER=nova -e POSTGRES_PASSWORD=nova -e POSTGRES_DB=nova \
  -p 5432:5432 postgres:16
```

Без Docker — обычная установка PostgreSQL, потом создать базу `nova`.

## Настройка

Скопируйте `.env.example` в `.env` (в папке `apps/api`) и впишите свои значения:

```
cp .env.example .env
```

Для Docker-команды выше строка подключения такая:

```
DATABASE_URL=postgresql://nova:nova@localhost:5432/nova
```

`.env` читается автоматически при старте API (файл `src/env.ts`).

## Создание таблиц

```
psql postgresql://nova:nova@localhost:5432/nova -f db/schema.sql
```

Схему можно запускать повторно — существующие таблицы и индексы не трогаются.
Если база создана **старой** версией схемы, один раз выполните:

```
psql postgresql://nova:nova@localhost:5432/nova -f db/migrations/001_audit_fix.sql
```

## Запуск

Из корня проекта:

```
npm install
npm run dev:api
```

Проверка: откройте http://localhost:3001/health — должно ответить
`{"status":"ok","database":true}`.

## Что работает

Все адреса API начинаются с `/api`:

- `POST /api/auth/request-code` — запрос кода на телефон
- `POST /api/auth/verify` — вход, выдаёт токен
- `POST /api/auth/logout` — выход
- `GET /api/listings?country=RU` — список с фильтрами, местом, радиусом, поиском (`country` обязателен)
- `GET /api/listings/count?country=RU` — счётчик для кнопки «Показать N»
- `GET /api/listings/:id` — одно объявление
- `POST /api/listings` — публикация (нужен токен `Authorization: Bearer …`)
- `GET /api/listings/my/list` — мои объявления
- `POST /api/listings/:id/close` — снять с публикации

Служебные: `GET /health` (с проверкой базы), `GET /api/health`.

Код входа при разработке печатается в терминал — SMS-провайдер
подключается отдельно.

## Чего пока нет

Загрузка фотографий, чат, модерация, уведомления, серверное избранное и корзина.
Таблицы под них в схеме уже есть. Модули `cart`, `favorites`, `search`, `shorts`,
`support`, `location` пока отвечают заглушкой `{ ok: true }`.

Веб-приложение сейчас работает автономно (localStorage) и к API ещё не подключено.
