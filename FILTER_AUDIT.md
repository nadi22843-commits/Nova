# Nova — финальная проверка фильтров

Проверено перед передачей разработчику: Web + Mobile.

Точечные исправления без изменения дизайна и маршрутов:
- Web теперь использует те же актуальные конфигурации категорий, что и общее ядро/Mobile (включая большой справочник авто, зависимость Марка → Модель и актуальные Work/Realty поля).
- Web регистрирует справочники и лениво загружает их на экране фильтров.
- При смене родительского фильтра очищается устаревшее дочернее значение (например BMW/X5 → Toyota больше не оставляет X5).
- matchItem учитывает deal-specific поля: фильтр продажи не вмешивается в аренду и наоборот; аналогично vacancy/resume/service.
- Исправлена ошибка пустой выдачи Web: использовалась несуществующая переменная region; теперь проверяется selection.placeId.
- Цена, диапазоны, select, toggle, seller, география/радиус и сортировка сохранены без изменения UX.

Дизайн, URL-маршруты и структура экранов не менялись.
