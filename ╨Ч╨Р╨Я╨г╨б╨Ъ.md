# Запуск Nova

## Что нужно

Node.js **22 LTS** (минимум 20.19 — этого требуют Vite и встроенная загрузка `.env` в API). Проверить: откройте терминал и наберите `node -v`.
Если команда не найдена — поставьте LTS-версию с nodejs.org.

## Запуск в VS Code

1. Распакуйте архив.
2. **File → Open Folder** и выберите папку, в которой лежит этот файл.
3. **Terminal → New Terminal** (или `Ctrl + ~`, на Mac `Cmd + ~`).
4. Выполните по очереди:

```
npm install
npm run dev
```

Первая команда идёт несколько минут — это нормально.

## Открыть на телефоне

После `npm run dev` в терминале появятся два адреса:

```
Local:   http://localhost:5173/
Network: http://192.168.1.42:5173/
```

Второй — для телефона. Наберите его в браузере телефона.
Компьютер и телефон должны быть в одной Wi-Fi сети.

Если адрес не открывается — почти всегда это брандмауэр Windows.
При первом запуске он спрашивает разрешение; нужно разрешить для частной сети.

Остановить сервер: `Ctrl + C` в терминале.

## Что посмотреть

**Экран выбора страны** появится сразу, он показывается один раз.
Выберите Россию.

**Главная** — 11 категорий.

**Недвижимость → Снять** — теперь показывает только аренду.
Раньше здесь была вперемешку продажа.

**Фильтры** — счётчик на кнопке пересчитывается на каждое изменение.
Наборы полей разные для разных типов объектов.

**Выбор места** — поиск по названию, вложенность, радиус.
Попробуйте ввести «Питер».

**Форма публикации** — шаги, прогресс, черновик.
Выйдите на середине и вернитесь: заполненное сохранится.

**`/system`** — состояние всех модулей.
Добавьте адрес в конец: `192.168.х.х:5173/system`

## Смена страны

Выбор страны сохраняется в браузере. Сменить страну: **Личный кабинет → «Сменить страну»**
(кнопка доступна и без входа).

Попробуйте Германию: цены станут в евро, а в выборе места появятся
Bundesland и München вместо российских регионов.

## Тесты

```
npm test
```

46 проверок автономности: категории, страны, справочники мест (веб и общее ядро).

Полная проверка перед сдачей: `npm run verify` (типы + тесты + сборка).

## Если что-то не работает

Скопируйте текст ошибки из терминала целиком — по нему видно причину.

Частые случаи:

- `npm: command not found` — не установлен Node.js
- `EADDRINUSE` — порт 5173 занят, закройте прошлый запуск
- Белый экран — откройте консоль браузера (F12), там будет причина
